# Simple TCP Server Socket

Computer Networks Laboratory project. This application implements a custom TCP socket server alongside a comprehensive technical report and a web asset directory.

## Project Structure

* **`Reti_Relazione_Tecnica.pdf`**: The official technical report detailing the project specifications, architectural design, protocol choices, and testing phases.

* **`TCP_Socket_Server.py`**: The core Python script implementing the TCP socket server logic to handle incoming client connections and requests.

* **`log.txt`**: Log file used by the application to record runtime events, connection states, and request histories.

* **`www/`**: A directory containing static web assets and media files (such as `.jpg`, `.png`, and `.webp` images) served or utilized during testing.

## Getting Started

### Prerequisites

Make sure you have Python installed on your system (Python 3.x recommended).

### Running the Server

To start the TCP socket server, navigate to the project directory and execute:

```
python TCP_Socket_Server.py
```

## Documentation

For an in-depth explanation of the network architecture, protocol implementation, and performance analysis, please refer to the `Reti_Relazione_Tecnica.pdf` document.
